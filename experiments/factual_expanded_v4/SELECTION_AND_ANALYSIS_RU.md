# Фиксация основного набора до первого основного ответа

200 PsiloQA и 200 TruthfulQA выбраны по хеш-порядку из одобренных кандидатов. Результаты новой модели не использовались для отбора. В PsiloQA выбран один вопрос на исходную wiki-статью; в TruthfulQA размечены семейства похожих шаблонов для кластерного анализа чувствительности. Номинальные 200 вопросов TruthfulQA не объявляются 200 независимыми семантическими задачами.

Проверка выполнена ассистентом, а не независимыми людьми: просмотр вопроса, эталона и выбранной ошибочной подсказки, сверка исходных строк и хешей, просмотр фрагментов PsiloQA. Это проверка соответствия зафиксированной разметке/тексту, не внешняя сертификация каждого факта. Для TruthfulQA evidence содержит сами эталонные ответы, а не независимо найденный источник. Первичные метки поэтому называются соответствием/противоречием эталону. Неизвестные парафразы не получают автоматически метку ошибки.

Примеры исключённых дефектов исходной разметки PsiloQA: «recombinant adenovirus serotype 5» против «Human adenovirus 5»; «POBr3» против «PBr3O»; «Six» против «6»; географическая часть правильного места; дата меньшей точности, совпадающая с эталоном. Фрагмент с HAL-разметкой не принимался автоматически за неправильный ответ на заданный вопрос.

После чтения всех первых 200 выбранных фрагментов дополнительно исключены четыре вопроса: вывод страны рождения из национальности; вывод гражданства при рождении из страны рождения; расстояние, приписанное другой железнодорожной станции; фрагмент, не содержащий запрошенного эпизода музыкального сотрудничества. Предварительный набор и решения сохранены с суффиксом before_excerpt_review. Четыре замены взяты далее из ранее одобренного хеш-порядка, их фрагменты также прочитаны. Основных ответов к этому моменту не было.

Каталог хранит все исходные correct/incorrect списки, но в rejected для основной оценки включена только выбранная проверенная подсказка (и противоположная полярность у явного бинарного вопроса). Остальные исходные incorrect-варианты сохраняются для аудита и автоматически не объявляются проверенными метками. Числовые и календарные варианты добавляются только по явным ограниченным правилам, без изменения значения числа или даты.

Неопределённость амплитуды вычисляется по независимым бинарным дополнениям неизвестных ячеек. Это консервативные внешние границы: если одинаковые неизвестные ответы должны иметь одинаковую истинностную метку, часть дополнений недопустима и границы могут сузиться. Границы не объявляются точными при таких дополнительных семантических ограничениях. Отказы сохраняются как отсутствие ответа; диапазон для них описывает гипотетические дополнения, а не установленную скрытую ошибку.

После завершения полной сетки сообщаются парные диапазоны по вопросам, их средние, доли всех статусов, отдельная динамика наличия ответа и число кластеров. Вопросы с неопределённостью не исключаются из знаменателей. При последующей полной семантической оценке необходим анализ чувствительности с ресэмплингом целых отмеченных семейств вопросов; обычный t-интервал по вопросам сам по себе не устраняет зависимость шаблонов. Не делается остановка или подбор модели по промежуточной значимости.
